Setup and the gain

Part 1 of Block Diffusion Rooflines: notation, costs, intensities and penalties; Proposition 1, what the formulas leave out, which side wins and the best batch, and the split of each intensity into a linear part and an attention part.

Part 1 of Block Diffusion RooflinesPrevious: SummaryNext: 2 · The linear part

In this chapter, we first lay down the setup and discuss the concept of arithmetic intensities, see Pope et al., 2022 for a more thorough introduction to the topic. Next, we derive the throughput gains of TD versus AR and discuss a few consequences of our main result.

The setup

What do we need to track?

In order for us to state our main result (Proposition 1), we need to define the key quantities which govern the inference throughput of AR and TD. These quantities determine whether moving bytes (weights and KV cache) or performing actual work (matrix multiplies) is the limiting factor, i.e., whether the model is memory-bound or compute-bound. In order to do so, we need to compute the FLOPs of a forward pass of an AR model and those of a TD model. Similarly, we need to compute how many bytes are moved during a forward pass of the AR and TD models. By doing so, we will be able to establish the arithmetic intensities of both models, i.e., to answer the question: "how many FLOPs are used for each byte that is moved by the model?".

We consider a batch of \(B\) sequences, each with \(C\) tokens in its KV cache. An AR step is one forward pass and advances each sequence by one token1. On the other hand, TD advances each sequence by a canvas of \(b\) tokens, in \(S\) denoising passes and one commit pass. This is block diffusion (Arriola et al., 2025) with a KV cache over committed canvases. Throughout the blogpost, our running example is DiffusionGemma 26B-A4B (DiffusionGemma technical report, 2026).

A denoising pass costs \(r\) times a forward pass2. Hence, a canvas costs \(\omega = Sr + 1\) forward passes, and TD commits \(\mathrm{TPF} = b/\omega\) tokens per forward pass. Figure 5 below illustrates the two paradigms.

In \(\omega = S + 1\) passes over one canvas, AR commits \(\omega\) tokens and TD commits \(b\).

Costs of a pass

In Definition 1, we give the per-token costs of the linear and attention operations. They do not depend on whether decoding is AR or TD. In Definition 2, we give the FLOPs and the bytes of one forward pass of TD and of AR. Don't forget to click on a formula to get a reminder of the associated symbols!

Definition 1Coverage function and per-token costs

Coverage function

\(U_{n,k}(N) = n\bigl[1-(1-\tfrac{k}{n})^{N}\bigr]\) the coverage function: the expected number of distinct units touched by \(N\) independent, uniformly random selections of \(k\) units out of \(n\), and \(n\) when \(k \ge n\)

Linear layers

\(E,\ k\) experts per MoE layer and experts each token selects
\(L\) layers, each with \(E\) experts
\(W^e\) parameters of one expert in one layer
\(W_{\mathrm{ne}}\) non-expert parameters of all layers, without the vocabulary

Shapes and precision

\(\mathcal G,\ \mathcal W,\ \mathcal S\) sets of the global-attention, sliding-window and sparse layers
\(n_q,\ n_{\mathrm{kv},\ell},\ h_\ell\) query heads, KV heads and head dimension of layer \(\ell\)
\(g = n_q/n_{\mathrm{kv},\ell}\) query heads per KV head on the global layers
\(w,\ m\) earlier tokens that a window layer sees, and cached tokens that each query selects in a sparse layer
\(n_{I,\ell},\ h_{I,\ell}\) heads and head dimension of the indexer of sparse layer \(\ell\)
\(s_w,\ s_{\mathrm{kv}},\ s_I\) bytes per weight (2 in BF16, 16-bit floats; 1 in FP8, 8-bit floats), per element of the KV cache and per element of the indexer's keys
\(\kappa^c\) K/V tensors that a layer caches per KV head and per token (2: keys and values stored separately; 1 for a global layer whose \(K = V\) is stored once)

Attention 3

\(\alpha_G = 4n_q\sum_{\ell\in\mathcal G}h_\ell\) attention FLOPs per query and per cached token, global layers
\(\alpha_W = 4n_q\sum_{\ell\in\mathcal W}h_\ell\) the same, sliding-window layers
\(\alpha_S = 4n_q\sum_{\ell\in\mathcal S}h_\ell\) the same, sparse layers, per selected token
\(\alpha_I = 2\sum_{\ell\in\mathcal S}n_{I,\ell}h_{I,\ell}\) the same, for the indexer, the scan that selects a sparse layer's tokens (Part 3)
\(\nu_G = s_{\mathrm{kv}}\sum_{\ell\in\mathcal G}\kappa^cn_{\mathrm{kv},\ell}h_\ell\) KV bytes per cached token, global layers
\(\nu_W = s_{\mathrm{kv}}\sum_{\ell\in\mathcal W}\kappa^cn_{\mathrm{kv},\ell}h_\ell\) the same, sliding-window layers
\(\nu_S = s_{\mathrm{kv}}\sum_{\ell\in\mathcal S}\kappa^cn_{\mathrm{kv},\ell}h_\ell\) the same, sparse layers, per selected token
\(\nu_I = s_I\sum_{\ell\in\mathcal S}h_{I,\ell}\) bytes per cached token of the scan's own cache (Part 3)
Definition 2FLOPs and bytes of a pass

\(F\) denotes FLOPs and \(Q\) bytes, per sequence and per pass, for an AR step and for a TD pass, each split into a linear part and an attention part.

Linear FLOPs

\[ \class{mj-ar}{F^{\mathrm{AR}}_{\mathrm{lin}}} = 2N_{\mathrm{act}},\qquad \class{mj-td}{F^{\mathrm{TD}}_{\mathrm{lin}}} = 2b\,N_{\mathrm{act}},\qquad N_{\mathrm{act}} = W_{\mathrm{ne}} + L\,k\,W^e. \]

Attention FLOPs

\[ \begin{aligned} \class{mj-ar}{F^{\mathrm{AR}}_{\mathrm{attn}}}(C) &= \alpha_G C + \alpha_W\min(C,w) + \alpha_S\min(C,m) + \alpha_I C,\\[2pt] \class{mj-td}{F^{\mathrm{TD}}_{\mathrm{attn}}}(C) &= b\,\class{mj-ar}{F^{\mathrm{AR}}_{\mathrm{attn}}}(C). \end{aligned} \]
\[ \begin{gathered} \class{mj-ar}{F^{\mathrm{AR}}_{\mathrm{attn}}}(C) = \alpha_G C + \alpha_W\min(C,w)\\ \qquad + \alpha_S\min(C,m) + \alpha_I C,\\[3pt] \class{mj-td}{F^{\mathrm{TD}}_{\mathrm{attn}}}(C) = b\,\class{mj-ar}{F^{\mathrm{AR}}_{\mathrm{attn}}}(C). \end{gathered} \]

Linear bytes

\[ \class{mj-ar}{W^{\mathrm{AR}}}(B) = W_{\mathrm{ne}} + L\,U_{E,k}(B)\,W^e,\qquad \class{mj-td}{W^{\mathrm{TD}}}(B) = W_{\mathrm{ne}} + L\,U_{E,k}(Bb)\,W^e. \]
\[ \class{mj-ar}{Q^{\mathrm{AR}}_{\mathrm{lin}}}(B) = \frac{s_w\class{mj-ar}{W^{\mathrm{AR}}}(B)}{B},\qquad \class{mj-td}{Q^{\mathrm{TD}}_{\mathrm{lin}}}(B) = \frac{s_w\class{mj-td}{W^{\mathrm{TD}}}(B)}{B}. \]

Attention bytes

\[ \begin{aligned} \class{mj-ar}{Q^{\mathrm{AR}}_{\mathrm{attn}}}(C) &= \nu_G C + \nu_W\min(C,w) + \nu_S\min(C,m) + \nu_I C,\\[2pt] \class{mj-td}{Q^{\mathrm{TD}}_{\mathrm{attn}}}(C) &= \nu_G C + \nu_W\min(C,w) + \nu_S\,U_{C,m}(b) + \nu_I C. \end{aligned} \]
\[ \begin{gathered} \class{mj-ar}{Q^{\mathrm{AR}}_{\mathrm{attn}}}(C) = \nu_G C + \nu_W\min(C,w)\\ \qquad + \nu_S\min(C,m) + \nu_I C,\\[3pt] \class{mj-td}{Q^{\mathrm{TD}}_{\mathrm{attn}}}(C) = \nu_G C + \nu_W\min(C,w)\\ \qquad + \nu_S\,U_{C,m}(b) + \nu_I C. \end{gathered} \]

The totals are \(F^X = F^X_{\mathrm{lin}} + F^X_{\mathrm{attn}}\) and \(Q^X = Q^X_{\mathrm{lin}} + Q^X_{\mathrm{attn}}\) for \(X \in \{\mathrm{AR}, \mathrm{TD}\}\).

Intensities and penalties

Whether a pass is memory-bound or compute-bound depends only on its arithmetic intensity, the ratio of its FLOPs to its bytes, compared with the ridge point of the accelerator (Definition 3).

TD is hurt more by sparsity than AR. The following penalties quantify this: on the linear layers, on attention and overall, they compare the bytes that a TD pass and an AR step read per sequence,

\[ \Pi_{\mathrm{lin}}(B) = \frac{\class{mj-td}{Q^{\mathrm{TD}}_{\mathrm{lin}}}(B)}{\class{mj-ar}{Q^{\mathrm{AR}}_{\mathrm{lin}}}(B)} = \frac{\class{mj-td}{W^{\mathrm{TD}}}(B)}{\class{mj-ar}{W^{\mathrm{AR}}}(B)},\qquad \Pi_{\mathrm{attn}}(C) = \frac{\class{mj-td}{Q^{\mathrm{TD}}_{\mathrm{attn}}}(C)}{\class{mj-ar}{Q^{\mathrm{AR}}_{\mathrm{attn}}}(C)},\qquad \Pi(B,C) = \frac{\class{mj-td}{Q^{\mathrm{TD}}}(B,C)}{\class{mj-ar}{Q^{\mathrm{AR}}}(B,C)}, \]
\[ \begin{gathered} \Pi_{\mathrm{lin}} = \frac{\class{mj-td}{Q^{\mathrm{TD}}_{\mathrm{lin}}}}{\class{mj-ar}{Q^{\mathrm{AR}}_{\mathrm{lin}}}} = \frac{\class{mj-td}{W^{\mathrm{TD}}}}{\class{mj-ar}{W^{\mathrm{AR}}}},\\[4pt] \Pi_{\mathrm{attn}} = \frac{\class{mj-td}{Q^{\mathrm{TD}}_{\mathrm{attn}}}}{\class{mj-ar}{Q^{\mathrm{AR}}_{\mathrm{attn}}}},\qquad \Pi = \frac{\class{mj-td}{Q^{\mathrm{TD}}}}{\class{mj-ar}{Q^{\mathrm{AR}}}}, \end{gathered} \]

so that \(\class{mj-td}{I^{\mathrm{TD}}_{\mathrm{lin}}} = b\,\class{mj-ar}{I^{\mathrm{AR}}_{\mathrm{lin}}}/\Pi_{\mathrm{lin}}\), \(\class{mj-td}{I^{\mathrm{TD}}_{\mathrm{attn}}} = b\,\class{mj-ar}{I^{\mathrm{AR}}_{\mathrm{attn}}}/\Pi_{\mathrm{attn}}\) and \(\class{mj-td}{I^{\mathrm{TD}}} = b\,\class{mj-ar}{I^{\mathrm{AR}}}/\Pi\).

We have that:

  • \(\Pi_{\mathrm{lin}}\) relates to the sparsity in Mixture of Experts (MoE).
  • \(\Pi_{\mathrm{attn}}\) relates to the sparsity in sparse attention layers. 4

The throughput gain

In this section, Proposition 1 gives the ratio of the TD and the AR throughput. We then read off which decoder wins in Corollary 1. Finally, Proposition 2 splits each intensity into a linear part and an attention part, which Parts 2 and 3 treat separately.

Main result

Proposition 1TD/AR throughput gain

Consider \(B\) sequences decoded together, at a context \(C\) held fixed over a canvas. A canvas commits \(b\) tokens per sequence after \(S\) denoising passes and one commit pass, and a denoising pass costs \(r\) times a commit pass, in FLOPs and in bytes. Assume

A1 · Roofline
On an accelerator with peak compute \(\pi\) (FLOP/s) and memory bandwidth \(\beta\) (bytes/s), a pass with \(F\) FLOPs and \(Q\) bytes read from memory takes \(\max(F/\pi,\,Q/\beta)\).
A2 · Costs
Per sequence, an AR step costs \(\class{mj-ar}{F^{\mathrm{AR}}}\) FLOPs and \(\class{mj-ar}{Q^{\mathrm{AR}}}\) bytes, and a TD pass \(\class{mj-td}{F^{\mathrm{TD}}}\) and \(\class{mj-td}{Q^{\mathrm{TD}}}\), as in Definition 2.
A3 · Routing
Expert routing and token selection are independent across positions and uniform: each token picks its \(k\) experts uniformly among the \(E\), and each query its \(m\) tokens uniformly among the \(C\).

Then TD's throughput over AR's is

\[ \boxed{\;\begin{gathered}\Gamma = \frac{1}{\omega}\cdot\frac{\min(\class{mj-td}{I^{\mathrm{TD}}},\,I^\star)}{\min(\class{mj-ar}{I^{\mathrm{AR}}},\,I^\star)},\\[6pt] \omega = S\,r+1,\qquad \class{mj-td}{I^{\mathrm{TD}}} = \frac{b}{\Pi}\,\class{mj-ar}{I^{\mathrm{AR}}}.\end{gathered}\;} \]
Proof
  1. For a pass with \(I = F/Q\): \(\max(F/\pi,\,Q/\beta) = \dfrac{F}{\beta}\max\Bigl(\dfrac{1}{I^\star},\dfrac{1}{I}\Bigr) = \dfrac{F}{\beta\,\min(I, I^\star)}\).
  2. AR. A step costs \(B\class{mj-ar}{F^{\mathrm{AR}}}\) FLOPs at intensity \(\class{mj-ar}{I^{\mathrm{AR}}}\) and yields \(B\) tokens: \(\class{mj-ar}{T^{\mathrm{AR}}} = \class{mj-ar}{F^{\mathrm{AR}}}\,/\,\bigl(\beta\min(\class{mj-ar}{I^{\mathrm{AR}}}, I^\star)\bigr)\) per token.
  3. TD. A commit pass costs \(B\class{mj-td}{F^{\mathrm{TD}}} = Bb\class{mj-ar}{F^{\mathrm{AR}}}\) FLOPs at intensity \(\class{mj-td}{I^{\mathrm{TD}}}\). A denoising pass multiplies both \(\class{mj-td}{F^{\mathrm{TD}}}\) and \(\class{mj-td}{Q^{\mathrm{TD}}}\) by \(r\), so it has the same intensity and takes \(r\) times as long. A canvas therefore takes \(\omega\) times one commit pass and yields \(Bb\) tokens: \(\class{mj-td}{T^{\mathrm{TD}}} = \omega \class{mj-ar}{F^{\mathrm{AR}}}\,/\,\bigl(\beta\min(\class{mj-td}{I^{\mathrm{TD}}}, I^\star)\bigr)\) per token.
  4. \(\Gamma = \class{mj-ar}{T^{\mathrm{AR}}}/\class{mj-td}{T^{\mathrm{TD}}}\), and \(\class{mj-td}{I^{\mathrm{TD}}} = \class{mj-td}{F^{\mathrm{TD}}}/\class{mj-td}{Q^{\mathrm{TD}}} = b\class{mj-ar}{F^{\mathrm{AR}}}/(\Pi \class{mj-ar}{Q^{\mathrm{AR}}}) = b\class{mj-ar}{I^{\mathrm{AR}}}/\Pi\) by Definition 4. \(\blacksquare\)

In practice, when profiling models, we often look at rooflines which plot the attainable FLOPs/s as a function of the arithmetic intensity. Proposition 1 can be read off the roofline: the ratio of TD's height to AR's height on the roofline plot is \(\frac{\min(\class{mj-td}{I^{\mathrm{TD}}}, I^\star)}{\min(\class{mj-ar}{I^{\mathrm{AR}}}, I^\star)}\). Hence, the throughput gain \(\Gamma\) satisfies \(\Gamma \geq 1\) if and only if this ratio is greater than the number of passes to commit a canvas \(\omega\). This is illustrated in Figure 6.

Figure 6 · interactive

Hiking the roofline.

The roofline is \(\min(\pi,\ I\beta)\), and the bracket is \(\min(\class{mj-td}{I^{\mathrm{TD}}}, I^\star)/\min(\class{mj-ar}{I^{\mathrm{AR}}}, I^\star)\).

So far we have looked at the formula from a methodology point of view (and we will dive even deeper in this aspect). However, we can also look at it in terms of hardware choice. In particular, under reasonable assumptions on the model, the throughput gain is non-decreasing in the ridge, i.e., the hardware arithmetic intensity, and it increases with the ridge while TD is compute-bound and AR is not. This suggests that as FLOPs are cheap and bytes are expensive, approaches like TD might be favored in the future. This is illustrated in Figure 7.

What the formulas leave out

Item Impact Assumption Description
Kernel efficiency ★★★ (A1) Kernels run below the peak rates \(\pi\) and \(\beta\) (Parts 6–8). In practice, we need to account for how much of the efficiency we can recover. We discuss this in detail in Parts 7 and 8.
Uneven and correlated routing ★★★ (A3) We have so far assumed independent and uniform routing. We will see in practice that this is not true and it impacts the results especially at low batch size.
Keys equal to values on the global layers ★★★ none: cache format \(\kappa^c\) DiffusionGemma's global layers use one tensor as both key and value, and we cache it twice (\(\kappa^c = 2\))5. Caching it once would double \(I_{\mathrm{attn}}\) to 16 and halve the long-context limit \(I^\star/(\omega I_{\mathrm{attn}})\) (Part 3) from 1.72 to 0.86.
Timing kernel by kernel ★★★ (A1) Adding each kernel's roofline time, \(\sum_c \max(F_c/\pi, Q_c/\beta)\), instead of (A1)'s single \(\max(F/\pi, Q/\beta)\) over the whole pass, is never faster and at most twice as slow.
Vocabulary and self-conditioning ★★★ (A2) Self-conditioning feeds each denoising pass the distribution predicted by the previous one, through the embedding matrix, so per token TD runs \(2S-1\) vocabulary-sized matrix multiplications. The effect is mostly seen at small context. At batch 1 and context 1k, the embedding adds 1.5 GB to an AR step's 6.4 GB. A TD denoising pass adds 1.5 GB for the head, 1.3 GB of logits and, in the 13 passes that feed back probabilities, 1.5 GB for the soft embedding. The gain therefore rises from 2.22 to 2.53; at larger batches TD pays these terms in FLOPs and they lower it.
Adaptive step counts ★★☆ none: the setup fixes \(S\) We fix the number of denoising passes but one main advantage of TD resides in its early commit strategies. We leave that for future work.
Small effects ★☆☆ (A2) Activations6, KV writes and the at most \(b\) keys inside the canvas can slightly move the gain.

Optimal gains and batch sizes

Proposition 1 compares two minima, so which decoder wins depends first on AR: if AR is compute-bound, TD loses, and otherwise the gain is the smaller of \(\mathrm{TPF}/\Pi\), set by the bytes, and \(I^\star/(\omega \class{mj-ar}{I^{\mathrm{AR}}})\), set by the compute that AR leaves idle (Corollary 1).

Corollary 1Gains and batch sizes

Under the assumptions of Proposition 1:

  1. If AR is compute-bound (\(\class{mj-ar}{I^{\mathrm{AR}}} \ge I^\star\)), then \(\Gamma \le 1/\omega\). Otherwise

    \[ \Gamma = \min\Bigl(\frac{\mathrm{TPF}}{\Pi},\ \frac{I^\star}{\omega\,\class{mj-ar}{I^{\mathrm{AR}}}}\Bigr),\quad \mathrm{TPF} = \frac{b}{\omega}. \]

  2. Let \(C\) be a context at which AR is memory-bound, assume that \(\Pi(\cdot, C)\) is non-increasing in the batch7, and let \(\class{mj-td}{B^{\mathrm{TD}}_\star}(C)\) be the batch that maximises \(\Gamma\) at this context, if it exists8. There are three cases:

    1. if \(\class{mj-td}{I^{\mathrm{TD}}} \ge I^\star\) already at \(B = 1\), then \(\class{mj-td}{B^{\mathrm{TD}}_\star}(C) = 1\);
    2. if \(\class{mj-td}{I^{\mathrm{TD}}} \lt I^\star\) at every batch, then \(\Gamma = \mathrm{TPF}/\Pi\) is non-decreasing in \(B\), and the largest batch that fits is best;
    3. otherwise, \(\class{mj-td}{B^{\mathrm{TD}}_\star}(C)\) is the batch at which \(\class{mj-td}{I^{\mathrm{TD}}} = I^\star\).
Proof

(1) If \(\class{mj-ar}{I^{\mathrm{AR}}} \ge I^\star\), the denominator of Proposition 1 is \(I^\star\) and the numerator is at most \(I^\star\), so \(\Gamma \le 1/\omega\). Otherwise the denominator is \(\class{mj-ar}{I^{\mathrm{AR}}}\), and \(\min(b\class{mj-ar}{I^{\mathrm{AR}}}/\Pi,\,I^\star)/\class{mj-ar}{I^{\mathrm{AR}}} = \min(b/\Pi,\,I^\star/\class{mj-ar}{I^{\mathrm{AR}}})\); dividing by \(\omega\) gives the formula. (2) Since \(\class{mj-ar}{W^{\mathrm{AR}}}(B)/B\) is non-increasing (proof of Proposition 4), \(\class{mj-ar}{I^{\mathrm{AR}}}(\cdot, C)\) is non-decreasing in \(B\). Hence, in \(\Gamma = \min(\mathrm{TPF}/\Pi,\ I^\star/(\omega \class{mj-ar}{I^{\mathrm{AR}}}))\), the first term is non-decreasing in \(B\) and the second is non-increasing, and the minimum is maximal where they cross, i.e., where \(\class{mj-td}{I^{\mathrm{TD}}} = b\,\class{mj-ar}{I^{\mathrm{AR}}}/\Pi = I^\star\) (c). If the first term is already the larger at \(B = 1\), the maximum is at \(B = 1\) (a); if it is the smaller at every batch, \(\Gamma\) is the first term, which is non-decreasing (b). \(\blacksquare\)

Linear and attention parts

So far, we have treated a TD pass and an AR step as single units. In fact, it can be easier to think of the arithmetic intensity of AR and of TD as a weighted average of the intensities of their linear and attention parts. This is shown rigorously in Proposition 2. The next two chapters are dedicated to analysing each setting, first the linear case in Part 2 and then the attention case in Part 3.

Proposition 2Linear and attention arithmetic intensities

Under (A2), for \(X \in \{\mathrm{AR}, \mathrm{TD}\}\), let \(\theta^X_{\mathrm{lin}} = Q^X_{\mathrm{lin}}/Q^X\) and \(\theta^X_{\mathrm{attn}} = Q^X_{\mathrm{attn}}/Q^X\) as in Definition 2. Then

\[ I^X = \theta^X_{\mathrm{lin}}\,I^X_{\mathrm{lin}} + \theta^X_{\mathrm{attn}}\,I^X_{\mathrm{attn}},\qquad \Pi = \class{mj-ar}{\theta^{\mathrm{AR}}_{\mathrm{lin}}}\,\Pi_{\mathrm{lin}} + \class{mj-ar}{\theta^{\mathrm{AR}}_{\mathrm{attn}}}\,\Pi_{\mathrm{attn}}. \]
\[ \begin{gathered} I^X = \theta^X_{\mathrm{lin}}\,I^X_{\mathrm{lin}} + \theta^X_{\mathrm{attn}}\,I^X_{\mathrm{attn}},\\[4pt] \Pi = \class{mj-ar}{\theta^{\mathrm{AR}}_{\mathrm{lin}}}\Pi_{\mathrm{lin}}\\ \qquad + \class{mj-ar}{\theta^{\mathrm{AR}}_{\mathrm{attn}}}\Pi_{\mathrm{attn}} . \end{gathered} \]
Proof

\(I^X = F^X/Q^X = \sum_c (Q^X_c/Q^X)(F^X_c/Q^X_c)\) over the two parts \(c\). For the penalty, \(\class{mj-td}{Q^{\mathrm{TD}}_c} = \Pi_c\,\class{mj-ar}{Q^{\mathrm{AR}}_c}\) by Definition 4, so \(\Pi = \sum_c \class{mj-td}{Q^{\mathrm{TD}}_c}/\class{mj-ar}{Q^{\mathrm{AR}}} = \sum_c \class{mj-ar}{\theta^{\mathrm{AR}}_c}\,\Pi_c\). \(\blacksquare\)
