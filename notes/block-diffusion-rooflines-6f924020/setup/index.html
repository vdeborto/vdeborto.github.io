Setup

Notation, costs, intensities, penalties.

Part 1 of Block Diffusion Rooflines (Previous: Summary | Next: 2 · The gain)

One forward pass advances a batch of \(B\) sequences, each with \(C\) tokens in its KV cache: by one token for AR, by a canvas of \(b\) tokens for TD, which takes \(S\) denoising passes and one commit pass.

Figure 1 · interactive

TD does more work per token, but reads each byte for more tokens.

Each slot is one forward pass, and every pass reads the weights once. Press play, change the canvas length \(b\) and the number of denoising passes \(S\), then switch the model from dense to MoE.

One sequence, batch 1, short context, and both decoders assumed memory-bound, so that a pass takes the time to read its weights; this fails for a dense model once the canvas is longer than about \(I^\star\) positions, where Corollary 1 caps the gain. A canvas costs \(\omega = S + 1\) passes (here \(r = 1\)) and commits \(b\) tokens; in the same \(\omega\) passes AR commits \(\omega\) tokens. For a dense model both passes read the same weights, and per committed token TD reads \(\omega/b = 1/\mathrm{TPF}\) times the bytes of AR: \(\Gamma = \mathrm{TPF}\). For an MoE model a canvas touches more experts than one token does, a TD pass reads \(\Pi_{\mathrm{lin}}\) times the weights of an AR step (the two bars, Proposition 3), and \(\Gamma = \mathrm{TPF}/\Pi_{\mathrm{lin}}\).

Definition 1Constants

In short. The sizes the costs depend on: active and total parameters, how many distinct experts a set of positions touches, and the attention FLOPs and KV bytes per cached token.

Linear layers

\(U_{n,k}(N) = n\bigl[1-(1-\tfrac{k}{n})^{N}\bigr]\) expected number of distinct units touched by \(N\) independent selections of \(k\) units out of \(n\)
\(\class{mj-ar}{W_{AR}}(B) = W_{\mathrm{ne}} + L\,U_{E,k}(B)\,W^e\) weights read by an AR step at batch \(B\), in parameters
\(\class{mj-td}{W_{TD}}(B) = W_{\mathrm{ne}} + L\,U_{E,k}(Bb)\,W^e\) weights read by a TD pass at batch \(B\), whose \(Bb\) positions route independently
\(2N_{\mathrm{act}}\) linear-layer FLOPs per position, whatever the context

Attention

\(\alpha_G = 4n_q\sum_{\ell\in\mathcal G}h_\ell\) attention FLOPs per query and per cached token, global layers
\(\alpha_W = 4n_q\sum_{\ell\in\mathcal W}h_\ell\) the same, sliding-window layers
\(\alpha_S\) the same, sparse layers (\(4n_q\sum h_\ell\) over them)
\(\alpha_I\) the same, for the scan that selects a sparse layer's tokens (§4)
\(\nu_G = s_{kv}\sum_{\ell\in\mathcal G}\kappa^cn_{kv,\ell}h_\ell\) KV bytes per cached token, global layers
\(\nu_W = s_{kv}\sum_{\ell\in\mathcal W}\kappa^cn_{kv,\ell}h_\ell\) the same, sliding-window layers
\(\nu_S\) the same, sparse layers
\(\nu_I\) bytes per cached token of the scan's own cache
\(U_{C,m}(n) = C\bigl[1-(1-\tfrac{m}{C})^{n}\bigr]\) cached tokens that \(n\) queries of one sequence read together in a sparse layer (the coverage function above, with tokens as units); \(U_{C,m}(1) = m\)
Definition 2FLOPs and bytes of a pass

In short. Per sequence, a TD pass does \(b\) times the FLOPs of an AR step; the weight bytes are shared by the batch and the cache bytes are not.

\(F\) denotes FLOPs and \(Q\) bytes, per sequence and per pass, for an AR step and for a TD pass, each split into a linear part and an attention part.

\[ \begin{aligned} \class{mj-ar}{F^{AR}_{\mathrm{lin}}} &= 2N_{\mathrm{act}}, & \class{mj-td}{F^{TD}_{\mathrm{lin}}} &= 2b\,N_{\mathrm{act}},\\[2pt] \class{mj-ar}{F^{AR}_{\mathrm{attn}}}(C) &= \alpha_G C + \alpha_W\min(C,w) + \alpha_S\min(C,m) + \alpha_I C, & \class{mj-td}{F^{TD}_{\mathrm{attn}}}(C) &= b\,\class{mj-ar}{F^{AR}_{\mathrm{attn}}}(C),\\[2pt] \class{mj-ar}{Q^{AR}_{\mathrm{lin}}}(B) &= s_w\class{mj-ar}{W_{AR}}(B)/B, & \class{mj-td}{Q^{TD}_{\mathrm{lin}}}(B) &= s_w\class{mj-td}{W_{TD}}(B)/B,\\[2pt] \class{mj-ar}{Q^{AR}_{\mathrm{attn}}}(C) &= \nu_G C + \nu_W\min(C,w) + \nu_S\min(C,m) + \nu_I C, & \class{mj-td}{Q^{TD}_{\mathrm{attn}}}(C) &= \nu_G C + \nu_W\min(C,w) + \nu_S\,U_{C,m}(b) + \nu_I C. \end{aligned} \]
\[ \begin{gathered} \class{mj-ar}{F^{AR}_{\mathrm{lin}}} = 2N_{\mathrm{act}},\qquad \class{mj-td}{F^{TD}_{\mathrm{lin}}} = 2b\,N_{\mathrm{act}},\\[3pt] \class{mj-ar}{F^{AR}_{\mathrm{attn}}}(C) = \alpha_G C + \alpha_W\min(C,w)\\ \qquad + \alpha_S\min(C,m) + \alpha_I C,\\[3pt] \class{mj-td}{F^{TD}_{\mathrm{attn}}}(C) = b\,\class{mj-ar}{F^{AR}_{\mathrm{attn}}}(C),\\[3pt] \class{mj-ar}{Q^{AR}_{\mathrm{lin}}}(B) = \frac{s_w\class{mj-ar}{W_{AR}}(B)}{B},\\[3pt] \class{mj-td}{Q^{TD}_{\mathrm{lin}}}(B) = \frac{s_w\class{mj-td}{W_{TD}}(B)}{B},\\[3pt] \class{mj-ar}{Q^{AR}_{\mathrm{attn}}}(C) = \nu_G C + \nu_W\min(C,w)\\ \qquad + \nu_S\min(C,m) + \nu_I C,\\[3pt] \class{mj-td}{Q^{TD}_{\mathrm{attn}}}(C) = \nu_G C + \nu_W\min(C,w)\\ \qquad + \nu_S\,U_{C,m}(b) + \nu_I C. \end{gathered} \]

The totals are \(F^X = F^X_{\mathrm{lin}} + F^X_{\mathrm{attn}}\) and \(Q^X = Q^X_{\mathrm{lin}} + Q^X_{\mathrm{attn}}\) for \(X \in \{AR, TD\}\).

Definition 3Arithmetic intensities, in FLOPs per byte read from memory

In short. Intensity is FLOPs per byte read from memory; a pass is compute-bound when its intensity reaches the ridge point \(I^\star = \pi/\beta\), 206 on an H200.

Definition 4Selected resources and the penalties

In short. A penalty is how many more bytes per sequence a TD pass reads than an AR step: \(\Pi_{\mathrm{lin}}\) from the experts its \(b\) positions touch, \(\Pi_{\mathrm{attn}}\) from the cached tokens that sparse layers select.

Two resources are selected by each position rather than read in full. A pass reads the union of its positions' selections, \(U_{n,k}(N)\) units for \(N\) independent selections of \(k\) out of \(n\). The penalty of a resource is the ratio of what a TD pass reads to what an AR step reads.
Resource units \(n\) picks \(k\) shared by \(N\) in an AR step \(N\) in a TD pass penalty
experts (per layer) \(E\) \(k\) the whole batch \(B\) \(Bb\) \(\Pi_E = \dfrac{U_{E,k}(Bb)}{U_{E,k}(B)}\)
cached tokens (sparse layer) \(C\) \(m\) one sequence 1 \(b\) \(\Pi_{\mathrm{sel}} = \dfrac{U_{C,m}(b)}{U_{C,m}(1)} = \dfrac{U_{C,m}(b)}{m}\) (selected tokens alone)

The penalties on the linear layers, on attention, and overall compare the bytes a TD pass and an AR step read per sequence:

\[ \Pi_{\mathrm{lin}}(B) = \frac{\class{mj-td}{Q^{TD}_{\mathrm{lin}}}(B)}{\class{mj-ar}{Q^{AR}_{\mathrm{lin}}}(B)} = \frac{\class{mj-td}{W_{TD}}(B)}{\class{mj-ar}{W_{AR}}(B)},\qquad \Pi_{\mathrm{attn}}(C) = \frac{\class{mj-td}{Q^{TD}_{\mathrm{attn}}}(C)}{\class{mj-ar}{Q^{AR}_{\mathrm{attn}}}(C)},\qquad \Pi(B,C) = \frac{\class{mj-td}{Q^{TD}}(B,C)}{\class{mj-ar}{Q^{AR}}(B,C)}, \]
\[ \begin{gathered} \Pi_{\mathrm{lin}} = \frac{\class{mj-td}{Q^{TD}_{\mathrm{lin}}}}{\class{mj-ar}{Q^{AR}_{\mathrm{lin}}}} = \frac{\class{mj-td}{W_{TD}}}{\class{mj-ar}{W_{AR}}},\\[4pt] \Pi_{\mathrm{attn}} = \frac{\class{mj-td}{Q^{TD}_{\mathrm{attn}}}}{\class{mj-ar}{Q^{AR}_{\mathrm{attn}}}},\qquad \Pi = \frac{\class{mj-td}{Q^{TD}}}{\class{mj-ar}{Q^{AR}}}, \end{gathered} \]

so that \(\class{mj-td}{I^{TD}_{\mathrm{lin}}} = b\,\class{mj-ar}{I^{AR}_{\mathrm{lin}}}/\Pi_{\mathrm{lin}}\), \(\class{mj-td}{I^{TD}_{\mathrm{attn}}} = b\,\class{mj-ar}{I^{AR}_{\mathrm{attn}}}/\Pi_{\mathrm{attn}}\) and \(\class{mj-td}{I_{TD}} = b\,\class{mj-ar}{I_{AR}}/\Pi\). For DiffusionGemma with dense attention, \(\Pi_{\mathrm{attn}} = 1\) and \(\Pi = \Pi_{\mathrm{lin}}\) at zero context: 7.9 at batch 1, 1.0 at batch 64.
