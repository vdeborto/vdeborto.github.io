# The symbols of the Block Diffusion Rooflines book. One file, two uses (bin/roofline_symbols.py):
#   - the Symbols page, the last page of the book: one table per "== Group", in this order;
#   - the symbol key (a click on a formula lists the symbols it uses), for the entries with "match".
# An entry is the symbol in TeX on its own line, then indented fields:
#   what:   the meaning; math goes in \( \)
#   in:     where the symbol is introduced ("Part 3", "Definition 2", "Proposition 8"); the build links it
#           and checks that a formula there uses the symbol
#   match:  JavaScript regular expression on a formula's TeX (the symbol key)
#   rank:   order in the symbol key, which keeps the 14 lowest ranks of a formula
#   scope:  T = only in Parts 1-7, P = only in Parts 8-11
#   key:    the symbol as the key shows it, when it differs from the page's
#   page:   no = in the key only
# A symbol that is not math is written "plain R1–R8". After a change: python3 -I bin/build-roofline.py

intro: This page lists every symbol of the blogpost, with its meaning and the place where it is introduced. The values in parentheses are those of DiffusionGemma 26B-A4B and of an H200. In the other chapters, a click on a formula lists the symbols that it uses.
